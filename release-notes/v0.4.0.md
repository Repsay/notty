# NOTTY v0.4.0

Existing pets now have Home Assistant controls for name, sex, neutered state and
birthday. Actions support breed edits, pet-to-litter-box associations, text memo
listing/detail/create/edit, account notification preferences and explicitly
confirmed irreversible device-statistics deletion. Profile saves preserve fresh
weight/unit, image metadata and every existing device binding. Shared pets cannot
be edited; HA name overrides and entity identities are retained.

Litter-box mode selection supports Auto, Scheduled and Soft stool, with fresh
identity/current-state validation and an enabled-plan prerequisite for Scheduled.
Both reminder reset buttons use the APK's action 3 and preserve the configured
cycle. Trash-bag interval changes and all four screen-language values are exposed.
Firmware update entities support explicit confirmation of a fresh eligible offer,
full notes and Boolean pending-target tracking. No measured percentage or
restart-persistent firmware progress is claimed.

Adds English/Dutch names, action selectors and icons. Fixes minimum-version
binary-sensor imports and pet device linking; CI now exercises Home Assistant
2026.3.0 as well as the locked development version. The timezone probe also runs
without Home Assistant installed. Feeders and water dispensers remain excluded.

The integration is experimental. New write contracts are traced from the APK
and tested with synthetic responses. Read-only live checks verified breed,
owner-profile and notification-category schemas. New pet/memo/notification/mode
writes, same-cycle resets, trash-bag interval changes, firmware installation and
statistics deletion still need owner validation; no such operations were run
for this release. Memo dates retain the NOTTY wall clock without inferred timezone.

After updating through HACS, restart Home Assistant. Existing entity unique IDs
and integration credentials are retained. Review action field descriptions before
using new writes in automations; statistics deletion requires
`confirm_irreversible: true` and cannot be undone.
